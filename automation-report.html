Project Scope

Application Under Test

SimpleShop is a custom e-commerce capstone website covering product search, cart behavior, authentication, user profile, shipping, payment, support tickets, persistence, and internal browser APIs.

Automation Design

  • Test runner: Playwright JavaScript
  • Browsers: chromium, firefox, webkit
  • Page objects: pages/shop.page.js and pages/pageFactory.js
  • Case logger: utils/caseLogger.js
  • Test data: data/testData.json
